# 每日构建通道

> 在正式发布之前，尝试最新的 Nitro 更改，每次向 `main` 分支提交都会自动发布构建版本。

你可以通过更新 `package.json` 加入 nightly 发布通道：

```json
{
  "devDependencies": {
    "nitro": "npm:nitro-nightly@latest"
  }
}
```

删除锁文件（`package-lock.json`、`yarn.lock`、`pnpm-lock.yaml`、`bun.lock` 或 `bun.lockb`）并重新安装依赖。

在 mono-repo 中使用 **Bun 作为包管理器** 时，需要确保 nitro 包被正确提升：

```toml [bunfig.toml]
[install]
publicHoistPattern = ["nitro*"]
```

避免使用 `<npm|pnpm|yarn|bun|deno> install nitro-nightly`；它无法正确安装。
如果遇到问题，请删除你的 `node_modules` 和锁文件，然后按照上述步骤操作。

要同时从 Nitro v2 迁移？请参阅[迁移指南](/docs/migration)。
