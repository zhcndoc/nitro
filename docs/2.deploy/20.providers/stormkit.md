# Stormkit

> 将 Nitro 应用部署到 Stormkit。

**预置配置：** `stormkit`

:read-more{title="Stormkit" to="https://www.stormkit.io"}

::note
可以通过[零配置](/deploy#zero-config-providers)与 [Stormkit](https://www.stormkit.io/) 集成。
::

## 设置

按照以下步骤在 Stormkit 上[创建新应用](https://app.stormkit.io/apps/new)。

![在 Stormkit 上创建新应用](/images/stormkit-new-app.png)

## 部署

默认情况下，当你将更改推送到主分支时，Stormkit 会自动部署你的应用。要触发手动部署（例如，进行首次部署），请点击 `Deploy now`。

![使用“立即部署”触发手动部署](/images/stormkit-deploy.png)
